# Mathematical Foundations for Economics Students

An open-access mathematical reference compendium covering trigonometry, 
calculus, and mathematical economics, designed for students of economics 
seeking rigorous mathematical foundations.

## Read Online

[isaxg.github.io/math_compendium](https://isaxg.github.io/math_compendium/)

## Built With

- [Quarto](https://quarto.org/) — document publishing system
- Python (matplotlib, numpy) — computational figures
- R — statistical graphics
- LaTeX (MathJax/TinyTeX) — mathematical typesetting

## About

This resource is independently developed under faculty supervision at 
Texas A&M University, Department of Economics. It is a work in progress 
designed for long-term expansion across additional mathematical subjects.
